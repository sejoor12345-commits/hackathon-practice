# 03. 완료 기준 (제3자가 예/아니오로 판정)

> 모든 기준은 **(1) 숫자가 하나 이상 있고 (2) 내가 아닌 사람이 결과물만 보고 예/아니오를 말할 수 있어야** 한다.
> 기준은 **사람이 먼저** 쓴다. AI는 그다음에 데이터를 만든다 (practice_01 3회차 배움).

## 나쁜 기준 → 좋은 기준

| 나쁜 기준 | 왜 나쁜가 | 좋은 기준 |
|---|---|---|
| 리포트가 자연스럽다 | 판정하는 사람마다 다름 | 리포트 10개 중 원문에 없는 숫자·시점·인과가 든 문장 0개 |
| 빠르다 | 기준점 없음 | 메모 10개 처리에 60초 이하 |
| 애매한 메모를 잘 찾는다 | "잘"이 뭔지 모름 | 숨긴 평가 세트 애매 6개 중 5개 이상 찾음 |

## 이번 작업의 기준

| # | 기준 (숫자 포함) | 판정 방법 (누가, 무엇을 보고) | 결과 (예/아니오) |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

## 숨긴 평가 세트
- [ ] 만드는 과정에서 **한 번도 안 본** 입력이 5개 이상 있다 (`eval_hidden/` 등)
- [ ] AI에게 "그 폴더는 열지 마"라고 지시했다
- [ ] 평가 결과를 보고 고쳤다면, 그 사실을 결과 문서에 적었다

## 자가 점검
- [ ] 기준마다 숫자가 있다
- [ ] 기준마다 "판정 방법" 칸이 채워져 있다
- [ ] 내가 아닌 사람에게 결과물과 이 표만 주면 판정할 수 있다
