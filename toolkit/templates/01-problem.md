# 01. 문제 카드

> 해커톤 첫 1시간 안에 채운다. **숫자 칸은 비워 두지 말고, 모르면 "가설"이라고 쓴다.**
> 숫자 옆에는 반드시 [실측] / [목표] / [가설] 중 하나를 붙인다.

## 한 문장 요약
<!-- 예: 영어학원 원장이 매달 강사 메모를 학부모 리포트로 다시 쓰는 데 이틀을 쓴다. -->
(누가) ______ 이/가 (언제) ______ 할 때 (무엇 때문에) ______ 해서 (얼마나) ______ 손해를 본다.

## 문제 카드

| 칸 | 내용 | 숫자 | 구분 |
|---|---|---|---|
| 누가 (한 사람으로 좁히기) | | 몇 명? | |
| 언제 (얼마나 자주) | | 월/주 몇 번? | |
| 지금은 어떻게 하나 | | 1번에 몇 분? | |
| 손해 (시간·돈·실수) | | 한 달에 몇 시간 / 몇 원 / 몇 건? | |
| 왜 지금까지 안 풀렸나 | | | |
| 에이전트가 "스스로 판단"하는 지점 | | | |

## 불편함과 손해 구분하기 (practice_01 1회차 배움)

| 불편함 (느낌) | 손해 (결과, 숫자) |
|---|---|
| 예: 메모가 대충이라 귀찮다 | 예: 리포트 80개 × 12분 = 16시간/월 |
| | |

## 증거
| 증거 | 출처 | 구분 |
|---|---|---|
| 예: 원장 인터뷰 1명 | 직접 들음 | 실측 |
| | | |

## 자가 점검 (제3자가 예/아니오로 판정)
- [ ] 한 문장 요약에 숫자가 1개 이상 있다
- [ ] "누가"가 한 종류의 사람이다 (예: "학원", "사람들" 아님)
- [ ] 손해 칸에 단위(분·원·건)가 있다
- [ ] 모든 숫자에 [실측]/[목표]/[가설] 표시가 있다
- [ ] 군 내부 정보·부대 자료가 들어 있지 않다
