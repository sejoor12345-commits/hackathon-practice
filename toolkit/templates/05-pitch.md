# 05. 3분 피칭 (문제 – 해결 – 데모 – 숫자 – 팀 – 요청)

> 연습은 `toolkit/pitch-timer.html`로 시간을 재면서 한다. 3번 이상 소리 내어 연습하고, 매번 점수를 남긴다.
> 숫자는 모두 [실측] / [목표] / [가설]을 말로도 구분한다. ("측정해 보니 ~", "목표는 ~", "아직 재 보지 않았지만 ~로 예상합니다")

| 구간 | 시간 | 해야 할 말 | 내 대본 |
|---|---|---|---|
| 문제 | 0:00–0:30 | 누가, 얼마나 자주, 얼마나 손해 (숫자 1개 이상) | |
| 해결 | 0:30–1:00 | 한 문장 정의 + 에이전트가 스스로 판단하는 지점 | |
| 데모 | 1:00–2:00 | 핵심 흐름 1개만. 클릭마다 한 문장 | |
| 숫자 | 2:00–2:30 | 실측 결과 + 한계 1개 (솔직하게) | |
| 팀 | 2:30–2:45 | 왜 우리가 이 문제를 풀 수 있나 (직접 겪음, 만든 것) | |
| 요청 | 2:45–3:00 | 심사위원/투자자에게 원하는 것 1개 (파일럿 대상, 데이터, 멘토링) | |

## 자가 점검
- [ ] 3분 안에 끝났다 (pitch-timer 기록)
- [ ] 첫 30초 안에 숫자가 나온다
- [ ] 데모 구간에 실제 화면이 나온다 (슬라이드 그림 아님)
- [ ] 한계를 1개 이상 스스로 말했다
- [ ] 요청이 하나로 구체적이다
