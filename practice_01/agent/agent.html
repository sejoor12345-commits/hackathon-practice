학부모 리포트 에이전트

강사 메모에서 근거 없는 평가를 찾아 강사에게 묻고, 문장마다 근거를 단 리포트를 씁니다. 메모는 모두 가짜입니다.

  1. 주장 뽑기
  2. 근거 확인
  3. 강사 질문
  4. 답변 반영
  5. 리포트 쓰기
  6. 자가 점검
사지방처럼 여럿이 쓰는 PC라면 다 쓴 뒤 키 지우기를 누르고 탭을 닫으세요. 키는 이 탭의 sessionStorage에만 있고, 탭을 닫으면 사라집니다. OpenRouter에서 키마다 사용 한도를 작게 걸어 두세요.
무료 모델 이름은 자주 바뀝니다. openrouter.ai/models 에서 가격이 0인 모델 id를 넣으세요. 한 번 실행에 호출 약 5~7회.
