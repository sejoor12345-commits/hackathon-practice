# practice_01 리포트 에이전트 (진짜로 돌아가는 판)

4회차 때는 Claude가 마크다운을 직접 써서 "구현"을 대신했습니다. 이 폴더는 **코드가 단계를 하나씩 실행하는 진짜 에이전트**입니다.

## 무엇을 하나

| 단계 | 누가 하나 (mock) | 누가 하나 (실제 모델) | 결과 |
|---|---|---|---|
| 1. 주장 뽑기 | 규칙(쉼표·문장 단위로 자르고 단어 목록으로 분류) | 모델 → 코드가 "원문에 그대로 있는 글인지" 확인 | 사실 / 평가 / 계획 |
| 2. 근거 확인 | 규칙(기준 1~3) | 모델 → 규칙 판정과 다르면 기록 | 정상 / 애매 |
| 3. 강사 질문 | 틀 문장 | 모델 → 학생 이름이 없으면 틀 문장으로 대신 | 질문 표 |
| 4. 답변 반영 | **코드** (질문을 다 만든 뒤에만 답변을 연다) | **코드** | 답변이 근거가 되는지 |
| 5. 리포트 쓰기 | 원문 조각 + 존댓말 끝맺음 | 모델 (문장마다 근거 인용 달기) | 문장 + 출처 |
| 6. 자가 점검 | **코드** | **코드** → 걸린 문장은 모델이 1번 고쳐 쓰고, 그래도 걸리면 뺀다 | 통과 / 고침 / 뺌 |

원칙: **문장은 모델이 쓰고, 확인은 코드가 한다.** 모델 출력이 형식에 안 맞으면 그 부분만 규칙으로 대신하고 기록합니다.

자가 점검이 잡는 것: 원문에 없는 숫자, 원문에 없는 시점(지난달·이번 달·요즘·3개월 등), 원문에 없는 인과(덕분에·때문에 등), 원문과 다른 인용, 없는 출처. 다른 학생과 비교하는 문장·부정적 내용은 빼지 않고 **원장 확인 표시**를 붙입니다.

### 실제 모델로 돌릴 때 (돈·키)

- OpenRouter 키를 **화면에 붙여 넣기만** 합니다. 브라우저는 그 탭의 sessionStorage에만 두고(탭 닫으면 사라짐), Colab은 `getpass`로 받아 어디에도 쓰지 않습니다. **키를 파일에 적어 커밋하지 마세요.**
- 사지방은 공용 PC이므로 끝나면 **키 지우기** → 탭 닫기. OpenRouter에서 키마다 사용 한도(credit limit)를 작게 걸어 두세요.
- 기본 모델은 `openrouter/free`(무료 모델 중 하나로 보내 주는 주소)입니다. 여러 개를 쉼표로 넣으면 앞 모델이 실패(429 등)할 때 다음 모델로 넘어갑니다.
- 1회 실행(메모 10~12개) = 모델 호출 약 5~7회.

## 한계 (솔직하게)

- mock 모드는 **단어 목록 규칙**입니다. 평가 세트에서 "더딘", "딴짓" 같은 처음 보는 표현을 놓쳤습니다(애매 6개 중 4개만 찾음).
- mock 리포트 문장은 원문을 거의 그대로 옮겨서 **어색합니다.** 학부모에게 그대로 보낼 글이 아닙니다. 자연스러운 문장은 실제 모델 모드에서 나오고, 그때 자가 점검이 중요해집니다.
- 실제 모델 모드는 **가짜 모델 함수로만 시험했습니다.** 진짜 무료 모델로는 아직 한 번도 재지 않았습니다.
