# [가짜] 평가용 강사 메모 (12개)

> 이 파일은 **가짜 데이터**입니다. 실제 학원·학생·강사와 관계없습니다.
> 에이전트 규칙(agent-core.js, agent.py)을 커밋한 **뒤에** 따로 만든 평가 세트입니다. 에이전트 규칙을 이 메모에 맞춰 고치지 않습니다.

1. [문서윤 / 이강사] 단어시험 평균 91점(지난달 85점). 숙제 4회 모두 제출. 다음 달 문법 심화반으로 이동 예정.
2. [배준혁 / 정강사] 요즘 수업 태도가 많이 산만해졌어요. 단어시험 평균 77점.
3. [신하린 / 서강사] 듣기 평가 점수가 올랐어요. 지난달 14/20에서 이번 달 17/20.
4. [류태오 / 이강사] 발음이 눈에 띄게 좋아졌어요. 다음 달 말하기 대회 준비 시작.
5. [권나은 / 정강사] 문제 푸는 속도가 빨라졌어요. 독해 지문 1개 평균 5분(지난달 7분).
6. [조민서 / 서강사] 성실한 학생입니다. 단어시험 평균 82점.
7. [한도겸 / 이강사] 결석 3회(보강 1회만 완료). 단어시험 평균 64점, 지난달 72점에서 8점 떨어짐. 다음 달 보충수업 2회 추가.
8. [임소율 / 정강사] 단어 암기가 더딘 편이에요. 단어시험 평균 79점.
9. [오하준 / 서강사] 수업 때 딴짓을 자주 해요. 단어시험 평균 73점.
10. [장예서 / 이강사] 문법 이해도가 높아졌어요. 단원평가 지난달 65점, 이번 달 81점.
11. [남궁현 / 정강사] 영어 실력이 많이 늘었어요. 자신감도 생겼고요.
12. [백지아 / 서강사] 이번 달 신규 등록(3주차). 레벨테스트 70점, 중급반 배정. 수업 중 발표 자원 3회.
