argument-hint: [작업 폴더 경로, 남은 시간]

범위를 점검한다. 대상: $ARGUMENTS (비어 있으면 가장 최근 `hack_*/` 또는 `practice_*/` 폴더)

1. `02-scope.md`와 실제 코드·커밋 기록을 읽는다.
2. 아래 표를 채운다. 판정은 "예/아니오"로만 쓰고 근거(파일·커밋)를 단다.
   | 점검 | 예/아니오 | 근거 |
   |---|---|---|
   | 핵심 흐름이 처음부터 끝까지 한 번 돌아간다 | | |
   | "안 만들 것"에 적힌 기능을 만들고 있지 않다 | | |
   | 가짜로 처리한 부분이 문서에 표시돼 있다 | | |
   | 배포 주소가 열린다 | | |
   | 남은 시간 중 25% 이상을 영상·README·피칭에 남겨 두었다 | | |
3. 남은 시간 안에 못 끝낼 것 같은 기능이 있으면 **빼거나 가짜로 바꿀 후보**를 1~3개 제안한다(지금 바로 고치지 않는다).
4. 사용자에게 "무엇을 뺄지"를 묻고 끝낸다.
