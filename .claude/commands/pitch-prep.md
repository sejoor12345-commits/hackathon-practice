3분 피칭을 준비한다. 대상: $ARGUMENTS

1. **사실 모으기** – 작업 폴더의 문서(문제 카드, 기준, 평가 결과, 로그, README)에서 발표에 쓸 숫자와 사실을 표로 모은다. 칸: 사실 / 숫자 / 실측·목표·가설 / 출처 파일. **저장소에 없는 숫자는 쓰지 않는다.** 필요한데 없으면 "재야 할 것" 목록으로 따로 적는다.
2. **대본** – `toolkit/templates/05-pitch.md` 순서(문제 30초 – 해결 30초 – 데모 60초 – 숫자 30초 – 팀 15초 – 요청 15초)로 쓴다. 한국어 기준 1초에 약 4~5음절로 길이를 맞추고, 구간마다 글자 수를 적는다. 숫자를 말할 때 "측정해 보니 / 목표는 / 아직 재지 않았지만"으로 구분한다. 한계를 1개 이상 넣는다.
3. **슬라이드 5장 개요** – 장마다 제목 한 줄, 화면에 보일 것(숫자 1개 크게), 말할 것 요약.
4. **예상 질문 5개** – `toolkit/pitch-timer.html`의 질문 은행과 대회 종류를 참고해 고르고, 30초 답과 근거(출처 파일)를 단다.
5. 결과를 `<작업 폴더>/pitch/script.md`와 `slides.md`에 저장하고, 사용자에게 **pitch-timer.html로 3번 소리 내어 연습한 뒤 기록**하라고 안내한다.
