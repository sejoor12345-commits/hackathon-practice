해커톤을 시작한다. 대회 정보: $ARGUMENTS

순서대로 하고, 각 단계가 끝날 때마다 사용자에게 짧게 보여 준 뒤 다음으로 넘어간다.

1. **공고 확인** – 링크가 있으면 읽고, 없으면 사용자에게 물어서 아래 표를 채운다. 모르는 칸은 "확인 필요"라고 쓴다. 지어내지 않는다.
   | 항목 | 내용 |
   |---|---|
   | 마감 (날짜·시각·시간대) | |
   | 참가 자격 (병사 가능? 휴학생? 팀 인원) | |
   | 제출물 (저장소, 영상 길이, 설명문) | |
   | 채점표와 배점 | |
   | 오프라인 참석 필요 여부 | |
   | 설치형 도구 필수 여부 (사지방에서 못 쓸 수 있음) | |
2. **작업 폴더** – `hack_<대회이름>/` 폴더를 만들고 `toolkit/templates/01-problem.md`, `02-scope.md`, `03-criteria.md`, `04-demo.md`, `05-pitch.md`, `06-retro.md`를 복사한다.
3. **문제 카드 초안** – 사용자가 겪은 문제를 2~3개 물어본 뒤 `01-problem.md`를 채운다. 숫자에는 [실측]/[목표]/[가설]을 붙이고, 사용자가 말하지 않은 숫자는 [가설]로 두고 확인할 방법을 적는다. 군 내부 정보가 들어가면 빼자고 말한다.
4. **범위·기준 초안** – `02-scope.md`(핵심 흐름 1개, 안 만들 것 3개 이상), `03-criteria.md`(숫자 포함, 제3자가 예/아니오로 판정 가능한 기준 3개)를 채운다. **기준은 사용자가 최종 확인**한다.
5. **시간표** – 남은 시간에 맞춰 `toolkit/timeline.md`를 바탕으로 시각별 표를 만든다. **마지막 25%는 영상·README·피칭**으로 비워 둔다.
6. **배포 먼저** – `toolkit/starter/`를 복사해 배포하는 순서를 안내한다(README의 클릭 순서).

마지막에 한국어로: (1) 만든 파일 목록 (2) 사용자가 지금 결정해야 할 것 3개 이하.
